# Security Policy

Lucid Browser is an experimental browser-engine research project. Current builds are **not safe for sensitive or general-purpose browsing**: they do not provide browser-grade sandboxing, site isolation, a complete origin security model, or a security audit.

Please do not enter passwords, payment details, private messages, or other sensitive data into Lucid.

## Reporting a vulnerability

Do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled. If private reporting is unavailable, contact the repository owner through GitHub and provide only a high-level description until a private channel is agreed.

Reports should include the affected commit or version, platform, impact, and a minimal reproduction that does not expose real user data.
