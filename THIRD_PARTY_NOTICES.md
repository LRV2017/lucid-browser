# Third-party notices

Lucid's desktop shell currently uses the Rust `eframe` / `egui` ecosystem for native application UI. This does not provide the web rendering engine and is not used to render web pages.

The engine crate currently has no third-party browser-engine dependency.

Before releases, generate and review a complete dependency/license inventory (for example with cargo-about), include required notices, and verify all dependency licenses are compatible with the chosen distribution model.
