# Lucid Design System

## Lucid Calm — default

The default experience is visually quiet, not feature-poor. The interface should be extremely clean while its controls, workspace cards, command palette, panels and shortcuts remain tactile and discoverable.

- Graphite/near-black surfaces with a restrained lavender undertone.
- Clear typography, generous spacing and a small number of high-value controls.
- Interactive quick-access cards, workspaces, command palette, library and optional panels.
- Gentle, short transitions; no constant motion or distracting ambient effects.
- Widgets are opt-in and individually configurable. No ads, sponsored content or forced feeds.

## Lucid Cyberpunk — alternate

The alternate interface aims for the information hierarchy and in-world player-computer feeling of a futuristic Night City HUD, rather than merely applying neon colors to Calm.

- Near-black panels, thin technical borders and angular visual groupings.
- Magenta/red/cyan status accents, condensed labels and high-density system readouts.
- Distinct module navigation for network, activity, downloads, bookmarks and system settings.
- Tactile selected states, status alerts, scanner-like transitions and technical microcopy.
- Original assets and layout. Do not reuse Cyberpunk 2077 logos, screenshots, fonts, artwork or proprietary UI assets.

## Shared interaction requirements

- Theme switching never closes tabs, changes the page, or loses state.
- Both themes use identical browser functionality and accessibility semantics.
- Motion, sound and visual effects are optional; honor reduced-motion preferences.
- Hover and selected states should clarify action, not create visual noise.
- No decorative control may be shown as functional unless it performs the indicated action.
